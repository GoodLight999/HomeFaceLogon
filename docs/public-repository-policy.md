# 公開リポジトリ運用ポリシー (Public Repository Policy)

本プロジェクトは初期設計から GitHub 等の公開リポジトリにて開発を進めます。
開発および運用時に個人の秘密情報や環境依存データがコミットされないよう、以下のポリシーを厳格に適用します。

## 1. コミットしてよいもの (Allowed to Commit)
- ソースコード、ビルド定義（CMakeLists.txt、vcxproj、sln など）
- 各フェーズの設計書、ADR (Architecture Decision Records)
- 復旧・回復手順書、テストマトリクス
- 秘密情報を含まない単体テスト・結合テストコード
- 明白なダミー値のみを含むサンプル設定ファイル（`config.example.json` など）
- 設定ファイルのスキーマ定義
- 顔認識モデル（ONNX等）のダウンロード用スクリプト、ライセンス、SHA-256 ハッシュリスト
- 完全に匿名化されたテスト結果レポート

## 2. 絶対にコミットしてはならないもの (Strictly Forbidden to Commit)
- **Microsoft アカウントのメールアドレス、パスワード（平文）**
- **Qualified User Name（完全修飾ユーザー名）の実値**
- **Windows ユーザー名、コンピューター名**
- **本物の Windows ユーザー SID (Security Identifier)**
- **カメラデバイスの Symbolic Link やデバイスインスタンス ID**
- **ユーザーの顔画像、動画、スクリーンショット**
- **顔の特徴量ベクトル（Face Template / Embedding）**
- **`secret.bin`、`face.bin` などの DPAPI 保護済み秘密データ**
- **開発機や実機で動作している本番用 `config.json`**
- **ログファイル (`*.log`、`*.trace`)、ETL ログ、イベントログ、クラッシュダンプ**
- **レジストリからエクスポートした実機データ (`*.reg`)**
- **PFX ファイル、秘密鍵、コード署名用証明書**
- **ローカル環境独自のテストレポートや、AI アシスタントのローカル対話履歴（作業スクラッチなど）**

## 3. ローカルデータ・テストデータの配置
本番稼働時の実データは `%ProgramData%\HomeFaceLogon\` に保存します。
開発中・テスト中にローカルデータをリポジトリ作業ツリーへ配置する必要がある場合は、以下のディレクトリ直下にのみ配置し、これらはすべて `.gitignore` により追跡から除外されます。
- `local/`
- `private/`
- `runtime-data/`
- `diagnostics/`
- `captures/`
- `test-results/`

## 4. 誤ってコミットした場合の対処フロー
万が一、秘密情報が公開履歴に混入した場合は、単にファイルを削除するだけでは不十分です。直ちに以下の手順を実行してください。
1.  リポジトリへの `git push` を直ちに停止します。
2.  漏洩した Microsoft アカウントのパスワードを変更します。
3.  ローカルの Face Template および DPAPI 秘密データを再生成します。
4.  Git の履歴書き換えツール（`git-filter-repo` など）を用いて、コミット履歴から該当データ（または該当コミット）を完全に消去します。
5.  すでに GitHub 等へ公開されている場合は、履歴消去後に force-push を行い、GitHub のサポート経由でキャッシュデータ等のクリーンアップを要請します。
6.  漏洩したパターンを再発防止のため `.gitignore` および `check-public-tree.ps1` の検査項目へ追加します。
