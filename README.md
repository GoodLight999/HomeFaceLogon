# Home Face Logon (MVP Phase 0 & 1)

Windows 11 x64 において、顔認識を利用したサインインおよびロック解除機能を実現するプロジェクトです。
現在は Phase 0（開発環境と復旧手段の確立）および Phase 1（Microsoft アカウント認証実証）の実装フェーズです。

## プロジェクトの概要

本プロジェクトは、Windows の標準的な認証機構や LSASS、Windows Hello などを改造せず、公開された API（Credential Provider V2）のみを利用して顔照合によるサインインを支援するものです。
顔照合に成功した場合にのみ、あらかじめ暗号化して保存された Microsoft アカウントのパスワードを Windows へ提出しログオンします。

> [!CAUTION]
> 本プロジェクトは自宅の固定デスクトップ PC（個人所有）を主な対象としており、写真や動画によるなりすまし攻撃の対策などは要件に含みません。また、いかなる場合でも Windows 標準の PIN やパスワードによるサインイン手段（System Provider）を隠したり無効化したりしません。

## ディレクトリ構成

- `docs/` : 設計資料、回復手順、リポジトリ公開ポリシー
- `tools/` : 開発ツール、公開前検査スクリプト、無効化スクリプトなど
- `config.example.json` : 設定ファイルのサンプル

## 公開リポジトリポリシー

本プロジェクトは GitHub 等で一般公開されることを前提として開発されています。
そのため、実 SID、メールアドレス、顔データ、DPAPI 秘密データ等の機密情報は一切リポジトリへ含めない運用ルールが適用されています。
詳細は `docs/public-repository-policy.md` を参照してください。
